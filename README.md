# `u3d`

Rust crate implementation of the [U3D](https://en.wikipedia.org/wiki/Universal_3D) (Universal 3D, ECMA-363) file format, most commonly found embedded in 3D PDFs.

## `u3d` Status

- [x] compression context
- [x] modifier chain
- [x] CLODBaseMeshContinuation
- [ ] CLODProgressiveMeshContinuation
- [x] export to .obj/.mtl
- [ ] set up fuzzing
- [ ] RHAdobeMeshResource
- [ ] C API for parsing/reading
